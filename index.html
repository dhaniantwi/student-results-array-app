Array in action

This is the central data structure used by the application.

const students = [
  { name: "Ama Mensah", id: "IT001", score: 78 },
  { name: "Kojo Asare", id: "IT002", score: 64 },
  { name: "Esi Boateng", id: "IT003", score: 91 }
];

// Access one record by index
students[0].name; // "Ama Mensah"

// Visit each record
students.forEach(student => {
  // process each student's score
});

How the array supports the system

1. Storage: students groups related records in one ordered collection.

2. Indexing: an array index provides direct access to a position, such as students[0].

3. Traversal: loops visit records to calculate the class average and pass rate.

4. Searching: the application checks array elements to find matching names, IDs or courses.

5. Updating: adding and removing records changes the collection as the class list changes.

Important limitation: this demo stores data in memory, so records reset when the page is refreshed. A production system would use persistent storage and access controls.
