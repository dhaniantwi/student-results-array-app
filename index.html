Assignment answer · Arrays as a data structure

Real-World Applications of Arrays

Introduction: An array is a data structure that stores a collection of elements under one variable name. Each element can be accessed using its position, called an index. Arrays are useful when a program needs to keep related values together and process them efficiently.

1. Real-world applications that use arrays

Student results managementStores students' scores or student records so a school system can calculate averages, identify the highest score, search for a student and determine pass rates.
Inventory managementStores product quantities, prices or product records so a shop can check stock, update quantities and identify items that need restocking.
Banking and transaction analysisHolds a sequence of transaction amounts for calculating totals, finding particular transactions and reviewing account activity.
Hospital and clinic systemsCan organise lists of appointments, ward observations or patient-related records for searching and processing. Sensitive patient information also requires secure, persistent storage and access controls.
Weather monitoringStores daily temperatures or rainfall readings so a system can calculate averages, find maximum and minimum values, and compare readings over time.
Image and audio processingRepresents pixels, colour values or sampled sound data in ordered collections that software processes to edit, display or analyse media.

2. Why arrays are necessary

  1. Organised storage: related values can be kept together instead of creating a separate variable for every item.
  2. Direct access by index: a program can access an element at a known position, for example scores[0].
  3. Efficient traversal: loops can process every element to calculate totals, averages, maximums or minimums.
  4. Simpler searching and sorting: programs can examine elements to find a target value or arrange data in a useful order.
  5. Easier maintenance: elements can be updated, and many array-based collections allow elements to be added or removed through appropriate operations.

Arrays are particularly suitable when data items are related and are often processed together. A limitation is that a basic array has a fixed length in some languages, and inserting or deleting elements may require shifting data. In JavaScript, arrays can grow or shrink dynamically. An array alone is also not a database: data held only in memory may be lost when a page is refreshed.

3. Selected application to develop: Student Results Management System

The application selected for this assignment is a Student Results Management System. It stores student names, identification numbers, courses and scores as objects inside one array. The user can add student results, search records, sort scores, remove records, and view the class average, highest score and pass rate.

How arrays support this application:

  1. Storage: the students array keeps all student records in one collection.
  2. Indexing: an element can be accessed by position, such as students[0].
  3. Traversal: array methods and loops process all records to calculate class statistics.
  4. Searching: the application checks array elements to find a matching student name, ID or course.
  5. Updating: new records can be added and existing records can be removed as the class list changes.

Conclusion: Arrays are important because they provide an organised way to store and process related data. They are used in education, retail, banking, healthcare, weather analysis and multimedia systems. The Student Results Management System demonstrates these benefits through searching, sorting and calculating statistics from a collection of student records.

const students = [
  { name: "Ama Mensah", id: "IT001", score: 78 },
  { name: "Kojo Asare", id: "IT002", score: 64 },
  { name: "Esi Boateng", id: "IT003", score: 91 }
];

// Access one record by index
students[0].name; // "Ama Mensah"

// Visit each record
students.forEach(student => {
  // process each student's score
});

How the array supports the system

1. Storage: students groups related records in one ordered collection.

2. Indexing: an array index provides direct access to a position, such as students[0].

3. Traversal: loops visit records to calculate the class average and pass rate.

4. Searching: the application checks array elements to find matching names, IDs or courses.

5. Updating: adding and removing records changes the collection as the class list changes.

Important limitation: this demo stores data in memory, so records reset when the page is refreshed. A production system would use persistent storage and access controls.
